# Customer Sales Data Cleaning Using Python

## 📌 Project Overview

This project demonstrates how I cleaned and prepared a customer sales dataset using Python and Pandas.

The main goal was to identify common data quality problems and prepare the dataset for further analysis.

## 🛠️ Tools Used

* Python
* Pandas
* Jupyter Notebook

## 🔍 Data Cleaning Tasks

The project includes:

* Dataset inspection
* Missing value detection
* Duplicate detection
* Missing value handling
* Duplicate removal
* Data type checking
* Cleaned dataset export

## 📊 Dataset

The dataset contains customer and sales-related information.
